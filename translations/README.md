# Translations

The plugin ships **English only** (`workspace/format_multitopic/lang/en/`), per the Moodle
plugins-directory policy. Additional language packs are kept here for submission to
[lang.moodle.org](https://lang.moodle.org) (AMOS) and are **not** bundled into the installable ZIP.

No non-English packs are maintained for this fork yet.
